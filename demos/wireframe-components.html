Component sheet — directional. React to the orbs, the path, the button styles, and the icon language. Everything derives from the approved light theme.

Details that carry the calm.

One signature object (the orbs on the path); everything else disciplined. This is how a minimal design ends up looking considered rather than plain.

1 · Orbs — the signature

Soft, matte spheres with a single highlight — a polished stone on paper, not a glowing bulb. Three states, and the state is the colour: grey = ahead, blue = you are here, gold = done. Only used for journey steps (and their small echo in deck headers).

3 · Buttons — three roles, one family

Rounded (12px), a hairline of depth (a subtle inset bottom edge — the "pressable" cue Brilliant uses), no gradients, no glow. Primary = the one thing to do next; secondary = the alternative; ghost = navigation. Gold pill = the "read/complete" toggle. Focus ring is in-palette and unmissable.

4 · Icons — one hairline set

Outline icons, 1.5px stroke, rounded caps — the same weight as the body text so they never shout. Ink by default; accent or gold only when the icon is a state. Drawn inline as SVG (no icon font, no library). Roughly a dozen needed across the whole guide.
